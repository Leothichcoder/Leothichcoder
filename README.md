# Leothichcoder — Cyber Security Portfolio

Portfolio package for a Cyber Security Fresher targeting **SOC Analyst / Security Analyst / Cyber Security Intern** roles.

## Portfolio strategy
- Lead with **SOC, log analysis, network security, web security and incident response**.
- Each project contains: `README.md`, `lab-report/`, `screenshots/`, `docs/`, `evidence/`.
- Only publish evidence produced from your own lab. Do not upload real credentials, tokens, private IPs, client data or sensitive information.

## Evidence standard
Screenshots in this portfolio are intentionally left for **real lab evidence**. Do not create fake screenshots. Use the filename checklist in each project and replace the placeholder instructions with your own captures.

## Ethics
All security testing should be performed only against systems you own or are explicitly authorized to test.
